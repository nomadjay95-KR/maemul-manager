# 개발 태스크 목록

> 기술 스택: Next.js 14 (App Router) + Supabase + Vercel + TypeScript + Tailwind CSS

---

## Phase 1 — MVP

### T001. 프로젝트 초기 설정

| 항목 | 내용 |
|------|------|
| **설명** | Next.js 14 App Router + TypeScript 프로젝트 생성. Tailwind CSS, ESLint, Prettier 설정. Supabase 클라이언트 라이브러리 설치 및 환경변수 구성. 폴더 구조(app/, components/, lib/, types/) 확정. |
| **의존성** | 없음 |
| **완료 기준** | `npm run dev`로 로컬 실행 확인. Supabase 연결 테스트 통과. lint/format 정상 동작. |

---

### T002. Supabase DB 스키마 설계 및 마이그레이션

| 항목 | 내용 |
|------|------|
| **설명** | `properties` 테이블 설계 (빌라/상가 공통 + 구분 컬럼). 주요 컬럼: id, type(villa/shop), address, unit_number, rooms, deal_type(월세/전세/매매), deposit, monthly_rent, jeonse, sale_price, loan_available, occupancy_status, move_out_month, owner_phone, owner_personality, door_password, lighting, repair_status, building_age, floor, area, premium, business_restriction, notes, memo, status(active/completed), created_at, updated_at. `property_images` 테이블: id, property_id(FK), image_url, order, created_at. RLS(Row Level Security) 정책 설정. |
| **의존성** | T001 |
| **완료 기준** | Supabase Dashboard에서 테이블 확인. TypeScript 타입 정의 파일(`types/database.ts`) 생성 완료. 샘플 데이터 INSERT/SELECT 정상 동작. |

### T003. 인증/잠금 화면 구현

| 항목 | 내용 |
|------|------|

| **의존성** | T001 |
| **완료 기준** | 올바른 비밀번호 입력 시 메인 화면 진입. 잘못된 비밀번호 시 에러 표시. 브라우저 새로고침 시 세션 유지. |

### T004. 레이아웃 및 탭 네비게이션 구현

| 항목 | 내용 |
|------|------|
| **설명** | 상단 탭 바: [빌라/다세대] [상가] [보관함] + 우측 잠금 버튼. 탭 전환 시 URL 변경(App Router 활용). 태블릿 최적화 레이아웃: 최소 터치 영역 44px, 적절한 패딩. 반응형: 태블릿 가로/세로 모드 대응. |
| **의존성** | T003 |
| **완료 기준** | 탭 전환이 즉시 반응. 가로/세로 모드에서 레이아웃 깨지지 않음. 잠금 버튼 클릭 시 잠금 화면 복귀. |

### T005. 매물 목록 화면 (카드 UI)

| 항목 | 내용 |
|------|------|
| **설명** | 매물을 카드 형태로 2열 그리드 표시. 카드에 표시할 정보: 대표사진(썸네일), 주소, 가격 요약, 방 개수, 입주 상태. 무한 스크롤 또는 페이지네이션. 빈 상태(매물 없음) UI. Supabase에서 데이터 fetch (Server Component 활용). |
| **의존성** | T002, T004 |
| **완료 기준** | 빌라 탭에서 빌라 매물만, 상가 탭에서 상가 매물만 표시. 카드 탭 시 상세 페이지 이동. 데이터 없을 때 빈 상태 안내 표시. |

---

### T006. 매물 등록 폼 구현

| 항목 | 내용 |
|------|------|
| **설명** | 빌라/상가 각각의 등록 폼 구현. 거래 유형 선택 시 관련 가격 필드만 노출(조건부 렌더링). 입주 상태가 '거주중'이면 이사 예정월 필드 노출. 필수 항목 유효성 검증(주소, 방 개수). 폼 제출 시 Supabase INSERT. 성공 후 목록으로 리다이렉트. 터치 친화적 입력 필드(큰 폰트, 충분한 간격). |
| **의존성** | T002, T004 |
| **완료 기준** | 빌라/상가 매물 각각 등록 가능. 필수값 미입력 시 에러 메시지 표시. 등록 후 목록에 즉시 반영. |

---

### T007. 매물 상세 화면

| 항목 | 내용 |
|------|------|
| **설명** | 모든 매물 정보를 섹션별로 표시. 집주인 연락처 탭 시 전화 앱 연동(`tel:` 링크). 비밀번호 기본 마스킹, [보기] 탭 시 노출. 수정 버튼 → 수정 폼으로 이동. 계약완료 버튼 → 상태 변경 확인 다이얼로그 → UPDATE. |
| **의존성** | T005 |
| **완료 기준** | 등록된 모든 정보가 정확히 표시됨. 전화 링크 동작. 비밀번호 마스킹/해제 동작. 계약완료 처리 후 목록에서 사라지고 보관함에서 확인 가능. |

---

### T008. 매물 수정/삭제 기능

| 항목 | 내용 |
|------|------|
| **설명** | 상세 화면에서 수정 버튼 클릭 시 기존 데이터가 채워진 폼 표시. 변경 사항 저장 시 Supabase UPDATE. 삭제는 별도 두지 않음(계약완료로 대체). 단, 잘못 등록한 경우를 위한 삭제 기능은 확인 다이얼로그 후 처리. |
| **의존성** | T006, T007 |
| **완료 기준** | 수정 후 상세 화면에 변경 사항 즉시 반영. 삭제 시 확인 후 DB에서 제거(또는 soft delete). |

### T009. 사진 업로드 기능

| 항목 | 내용 |
|------|------|
| **설명** | 매물 등록/수정 시 사진 업로드 (최대 10장). Supabase Storage 버킷 생성 및 연동. 업로드 전 클라이언트 사이드 이미지 리사이즈/압축 (max 1920px, quality 80%). 업로드 진행률 표시. 업로드된 사진 미리보기 및 개별 삭제. 상세 화면에서 가로 스크롤 갤러리로 표시. |
| **의존성** | T002, T006 |
| **완료 기준** | 핸드폰/태블릿 카메라로 촬영한 사진 업로드 성공. 10장 초과 시 제한 안내. 상세 화면에서 사진 가로 스크롤 확인. 사진 탭 시 확대 보기. |

### T010. 검색 및 필터 기능
